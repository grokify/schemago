# Release Notes: schemakit v0.5.0

**Release Date:** 2026-08-23

## Overview

This release adds the **navigable profile** for human-reviewable, AI-authored schemas and a **`generate --check` drift guard** that keeps a committed schema honest against its Go structs in CI.

## Highlights

- **Navigable Profile**: Lint for flat, locally-comprehensible schemas — shallow nesting, predictable references, ID fields
- **Generate Drift Guard**: `generate --check` fails when a committed schema is out of sync with its Go source

## New Features

### Navigable Profile

A new `navigable` lint profile enforces patterns that make schemas easy for humans to review and for AI agents to author:

```bash
schemakit lint schema.json --profile navigable
```

| Check | Severity | Rationale |
|-------|----------|-----------|
| `deep-nesting` | Error | Object nesting deeper than 2 levels is hard to navigate |
| `deep-array-nesting` | Warning | Arrays of arrays of objects reduce navigability |
| `missing-id-field` | Warning | Array items without an ID field can't be cross-referenced |

See the [Profiles reference](../reference/profiles.md#navigable-profile) for design principles and examples.

### Generate Drift Guard (`--check`)

`schemakit generate --check` regenerates the schema in memory and compares it to the committed `-o` file, exiting non-zero on drift without rewriting the file — so schemas can't silently fall out of sync with their Go source of truth:

```bash
# CI drift guard
schemakit generate -o schema.json --check github.com/myorg/myproject/types Config
```

Pair it with a `//go:generate` directive so `go generate ./...` refreshes the schema and CI enforces it:

```go
//go:generate schemakit generate -o schema.json github.com/myorg/myproject/types Config
```

## Installation

### Homebrew

```bash
brew install grokify/tap/schemakit
```

### Go Install

```bash
go install github.com/grokify/schemakit/cmd/schemakit@latest
```

## Commands

| Command | Description |
|---------|-------------|
| `schemakit lint` | Check schemas for static type compatibility (profiles: default, scale, navigable) |
| `schemakit generate` | Generate JSON Schema from Go struct types (`--check` for drift guard) |
| `schemakit doc` | Generate Markdown documentation from Go types |
| `schemakit version` | Print version information |
