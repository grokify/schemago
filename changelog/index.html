    Changelog¶

    All notable changes to this project will be documented in this file.

    The format is based on Keep a Changelog, this project adheres to Semantic Versioning, commits follow Conventional Commits, and this changelog is generated by Structured Changelog.

    Unreleased¶

    v0.5.0 - 2026-08-23 (5084c92)¶

    Highlights¶

    • Navigable profile for human-reviewable, AI-authored schemas (flat structure, shallow references, ID fields)
    • generate --check drift guard to keep committed schemas in sync with their Go structs in CI

    Added¶

    • navigable lint profile enforcing flat structure and local comprehensibility: deep-nesting (error), deep-array-nesting (warning), missing-id-field (warning) (d951be7)
    • generate --check flag that regenerates the schema in memory and fails on drift against the committed -o file, without rewriting it (d7ca541)

    Dependencies¶

    • 2 dependency updates

    Documentation¶

    • Navigable profile reference and examples (742a733)
    • Update README badges/shields (639ae95)

    Tests¶

    • Tests for the navigable profile checks (b4c5556)

    Internal¶

    • Drop unused path parameter from isArrayOfArraysOfObjects (unparam) (5084c92)
    • gofmt formatting fix (79aabec)

    v0.4.0 - 2026-04-18¶

    Highlights¶

    • Rename to schemakit and add doc command for Markdown documentation generation
    • Enum extraction from Go source with descriptions
    • MkDocs documentation site with spec documentation guide

    Breaking¶

    • Rename binary from schemalint to schemakit (299d3d9)
    • Rename module from github.com/grokify/schemalint to github.com/grokify/schemakit (299d3d9)

    Added¶

    • schemakit doc command to generate Markdown documentation from Go struct types (2803436)
    • Extract package doc comments, type descriptions, and field comments via reflection (2803436)
    • Generate required/optional field tables with JSON names and types (2803436)
    • Support --title and --version flags for documentation headers (2803436)
    • Enum type extraction from type X string declarations (709ccaf)
    • Enum value extraction from const blocks with doc comment descriptions (709ccaf)
    • --prepend flag to include custom header content (overview, examples, references) (709ccaf)
    • Separate Type Reference and Enum Reference sections in generated docs (709ccaf)

    Documentation¶

    • MkDocs site in docs/ with comprehensive documentation (47a2d4d)
    • Spec Documentation Guide explaining auto-gen vs human authoring (47a2d4d)
    • Go-First Workflow guide with CI integration examples (47a2d4d)
    • Lint checks and profiles reference documentation (47a2d4d)
    • Update README with schemakit branding and doc command usage (c38b257)
    • Add Go-first workflow diagram showing generate and doc commands (c38b257)
    • Release notes for v0.3.0 and v0.4.0 (f2fcaa5)

    v0.3.0 - 2026-02-09¶

    Highlights¶

    • Generate JSON Schema from Go struct types using invopop/jsonschema

    Added¶

    • schemalint generate command to generate JSON Schema from Go struct types (1148f63)
    • Support for both local (GOPATH/src) and remote Go modules in schema generation (1148f63)
    • GitHub Actions release workflow for GoReleaser (44a4252)

    Changed¶

    • Rename ROADMAP.json/md to TASKS.json/md (1148f63)

    Fixed¶

    • Fix .gitignore pattern to not exclude cmd/schemalint/ files (1148f63)

    v0.2.0 - 2026-02-08¶

    Highlights¶

    • Rename to schemalint and add scale profile for strict static type compatibility

    Breaking¶

    • Rename binary from schemago to schemalint (a96efd5)
    • Rename module from github.com/grokify/schemago to github.com/grokify/schemalint (a96efd5)

    Added¶

    • --profile / -p flag to select linting profile (default, scale) (c0fed40)
    • Scale profile with composition-disallowed rule: disallow anyOf, oneOf, allOf (c0fed40)
    • Scale profile with additional-properties-disallowed rule: disallow additionalProperties: true (c0fed40)
    • Scale profile with missing-type rule: require explicit type field (c0fed40)
    • Scale profile with mixed-type-disallowed rule: disallow type arrays like ["string", "number"] (c0fed40)
    • Goreleaser configuration for cross-platform builds and Homebrew tap (b5d1fab)
    • --property-case flag to enforce property naming conventions (e.g., camelCase, snake_case) (73ed44f)

    Changed¶

    • Update CLI description to emphasize static type compatibility for all languages (Go, Rust, TypeScript, etc.) (a96efd5)

    Documentation¶

    • README with scale profile docs and Homebrew installation (3d4a088)
    • Release notes for v0.2.0 (3d4a088)
    • PRD, TRD, and ROADMAP updated for schemalint (f7e418d)

    v0.1.0 - 2026-01-17¶

    Highlights¶

    • Initial release with JSON Schema linter for Go compatibility

    Added¶

    • CLI with lint and version commands using cobra (f8ed488)
    • JSON Schema parser for linting (supports $defs, definitions, anyOf, oneOf) (f8ed488)
    • Union detection with discriminator field analysis (f8ed488)
    • Nullable pattern detection (anyOf: [T, null]) (f8ed488)
    • Reference pattern detection (anyOf: [ComponentReference, BaseXxx]) (f8ed488)
    • Configurable discriminator field priority (component_type, type, kind) (f8ed488)
    • Multiple output formats: text (default), JSON, GitHub Actions annotations (f8ed488)
    • Exit codes: 0 (ok), 1 (errors), 2 (warnings only) (f8ed488)

    Documentation¶

    • Product Requirements Document (PRD.md) (b0e491a)
    • Technical Requirements Document (TRD.md) (b0e491a)
    • README with installation and usage instructions (b0e491a)
